## Inline and display math

Inline notation stays in the sentence: arithmetic intensity is $I = F / B$, with $F$ floating-point operations and $B$ bytes transferred.

A conceptual roofline model bounds attainable performance:

$$
P(I) = \min\left(P_{\mathrm{peak}},\; \beta I\right)
$$

Here $P_{\mathrm{peak}}$ is peak compute throughput and $\beta$ is memory bandwidth. The notation is typeset at build time, including accessible MathML.[^math]

Long equations scroll horizontally within their own container:

$$
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^{\mathsf T}}{\sqrt{d_k}}+M\right)V,\qquad Q\in\mathbb{R}^{n\times d_k},\quad K\in\mathbb{R}^{m\times d_k},\quad V\in\mathbb{R}^{m\times d_v},\quad M\in\mathbb{R}^{n\times m}
$$

## Code you can copy

The button copies the original code without line numbers or surrounding UI text.

```python
def arithmetic_intensity(flops: float, bytes_transferred: float) -> float:
    """Return floating-point operations per byte transferred."""
    if bytes_transferred <= 0:
        raise ValueError("bytes_transferred must be positive")
    return flops / bytes_transferred
```
